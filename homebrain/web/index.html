Your enabled sources are checked every hour. Run an analysis any time.

Traffic samples one road segment near the configured home point. Market quotes may be delayed and are not financial advice; news headlines are unverified; event availability can change. TomTom, Finnhub, and Ticketmaster API keys are optional and stay in your local environment; Google News RSS and Open-Meteo weather require no key. Gmail reads only sender, subject, date, and labels from the 20 most recent inbox messages; it never fetches message bodies. GitHub reads issue, pull-request, and release metadata for up to five selected repositories; it does not fetch source code or make changes. URLs use GET only and do not send authorization headers.
